Give native code a clean build room.

CDevel is the Airlock workspace for C, C++, and other native toolchains. Use it when the job needs compilers, headers, linkers, and a build that does not depend on the host setup.

Open CDevel on Docker Hub ↗Run the workflow

Build and test a native project

Mount a small CMake project, configure it in the workspace, compile it, and run its tests. This is a concrete reason to use CDevel: the agent gets a complete native toolchain in a known environment.
