Keep the boundary explicit

An Airlock workspace does not need the host Docker socket. When container workflows are required, the development images can run a rootless Docker daemon inside the workspace. The outer runtime still decides which mounts, ports, devices, and environment variables are allowed through.

Not a magic security claim: Airlock makes the boundary inspectable and configurable. Review the mounts and permissions for the work you are about to run.
