OPENJ / METRICS INFLUX
OpenJ / Libraries / Metrics InfluxMake JVM metrics useful

Turn JVM activity into a useful time series.

Dropwizard Metrics Influx connects Java and Spark instrumentation to InfluxDB line protocol without forcing each application to invent its own measurement and tag scheme.

View the source ↗Maven Central ↗

A Spark metric with a stable shape

Spark emits names containing application ids, roles, and executor ids. The Spark sink turns those moving parts into a stable measurement plus tags.

app-20260807163931-0000.1.executor.recordsRead

measurement=executor.recordsRead
application=stream-writer
role=executor
executor_id=1
>> becomes a queryable Influx measurement with consistent dimensions

Report ordinary JVM metrics

The core reporter handles InfluxDB line protocol for Dropwizard Metrics 5. The Metrics 4 adapter reuses the same transformation and sender path.

spark.metrics.conf.driver.sink.influx.class=io.teknek.metricsinflux.spark.InfluxDbSinkReporter
  <groupId>io.teknek.metricsinflux</groupId>
  <artifactId>dropwizardmetrics-influx-core</artifactId>
  <version>0.0.4</version>
</dependency>

Useful when: Java or Spark metrics need stable measurements, tags, and a direct route to InfluxDB.
