Reckoning / model support

Supported models

Reckoning is a general-purpose JVM inference engine for local generation, embeddings, classification, tokenization, quantization, and specialized diffusion workflows.

Classifiers

The documented classification path is intended primarily for encoder families:

  • BERT: sequence classification such as jailbreak detection.
  • XLM-RoBERTa: multilingual language classification.

The shared builder can technically attempt classification for other dispatched families, but those combinations are not generally validated as classifier checkpoints.

Tokenizers

The Grace tokenizer layer supports model-aware loading of:

  • BERT and XLM-RoBERTa tokenizers
  • Llama and Qwen-style tokenizers
  • Gemma tokenizers
  • Byte-level BPE and fast tokenizer JSON files
  • Added tokens, special-token metadata, and chat templates

Tokenizer behavior is part of model support. BOS/EOS handling, reserved tokens, and chat_template.jinja can materially change model behavior.

Tool support is not purely an architecture property. It depends on the checkpoint’s chat template, tokenizer, output format, and tool-call parser. LLMON support is specific to LLMON-trained Granite checkpoints, not every Granite model.

How to read status

  • First-class: normal dispatch, tests, and documented usage.
  • Supported: working implementation with narrower validation.
  • Specialized: separate runtime behavior such as diffusion.
  • Active support: currently being ported or validated.
  • Help wanted: code exists, but output correctness or parity is not reliable enough to call supported.
  • Implemented; registration pending: model code exists but automatic dispatch is incomplete.
