Model Notes: Qwen3-0.6B-JQ4

Qwen3-0.6B-JQ4 is impressive for its size: it can generate meaningful text from a small local footprint. It supports thinking and tool calls, but eliciting those responses can be challenging even when the prompt directly asks for them.

The model ultimately has to decide from the prompt that it should call a tool. Smaller models like this may not make that decision reliably every time. The output-head-quantization option is disabled for this model because it causes model collapse and gibberish output.
