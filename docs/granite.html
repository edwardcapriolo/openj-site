import io.teknek.reckoning.safetensors.fetch.*;

    "edwardcapriolo", "granite-4.1-3b-llmon-preview-JQ4");

try (AbstractModel model = AutoModelForCausaLm
        .newBuilder(fetch).build()) {
    PromptContext prompt = model.promptSupport().orElseThrow()
        .builder().addUserMessage("Hello").build();
    Response response = model.generate(prompt);
    System.out.println(response.responseText);
}

Model Notes: Granite 4.1 3B LLMON-preview

Granite 4.1 3B LLMON uses 40 dense decoder layers, 40 query heads, 8 KV heads, a 2560-wide hidden state, and Granite-specific embedding, attention, residual, and logits scaling.

LLMON is an interchange representation, not a separate transformer architecture. The LLMON DSL page shows how to compose the structured prompt without writing reserved-token markup by hand.

The published Q4 model was generated from the BF16 checkpoint using Reckoning’s projection-only quantization policy. Its model directory preserves the tokenizer, chat template, configuration, and quantization manifest.
