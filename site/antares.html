Give a small model a codebase to investigate.

Antares uses a local model to locate likely vulnerabilities in a repository. It searches, reads, and reports exact file paths while asking before it runs terminal commands.

View the source ↗See the investigation

A security investigation, not a chatbot

Point Antares at a repository and give it a vulnerability pattern to look for. The model uses terminal-style tools to explore the code, then returns the files it believes are vulnerable.

./deliverance-antares-cli/run-server-antares-1b.sh

./deliverance-antares-cli/run-showcase-cwe78.sh
>> investigates a local repository for CWE-78 command injection

Watch the reasoning move

Antares keeps the investigation visible. You can see the search, inspect the file it found, and approve each command before it runs:

[tool] terminal rg -n "\.exec\(" .
[approval] y/N: y
[result]
./src/main/java/demo/ArchiveController.java:8:
    return Runtime.getRuntime().exec(command);

[tool] read_file src/main/java/demo/ArchiveController.java
[tool] submit_vulnerable_files
>> returns [src/main/java/demo/ArchiveController.java]

Start with a question

The direct command lets you provide a repository, model, CWE, and plain-language investigation query:

java -jar "$(sh deliverance-antares-cli/resolve_antares_cli_jar.sh)" \
  --repo path/to/repository \
  --endpoint http://127.0.0.1:18085/v1 \
  --model antares-1b-JQ4 \
  --cwe CWE-78 \
  --query "Look for user-controlled input reaching Runtime.exec, ProcessBuilder, shell commands, or command string concatenation." \
  --max-tool-calls 4

Keep the airlock visible

By default, Antares asks for approval before every terminal or bash command. Say n when a command is not appropriate. Unattended mode belongs inside a sandbox or container:

./deliverance-antares-cli/run-showcase-cwe78.sh \
  --yes-run-commands

Local by design: the model can inspect sensitive source code through a local InferJ server instead of sending the repository to a hosted API.

What Antares returns

Antares is focused on vulnerability localization: finding the files that deserve attention. It validates repository-relative paths and rejects globs, directories, missing files, absolute paths, and parent traversal.

>> returns a ranked list of exact vulnerable file paths and a short summary

Built for local experiments

The module runs an Antares-style workflow against an OpenAI-compatible InferJ completions endpoint. It streams output, keeps tool calls visible, and includes a small local smoke benchmark for comparing submitted files with expected vulnerable files.
